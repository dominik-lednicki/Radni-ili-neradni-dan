# Workday Checker (Radni ili neradni dan)

A quick JavaScript web application made as a school homework to determine whether a specified day is a working day or a non-working day.

## Tech Stack
* HTML5[cite: 6]
* JavaScript[cite: 6]

## How to Run
1. Clone or download the repository[cite: 6].
2. Open `index.html` in any web browser[cite: 6].
